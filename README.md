# Currículo — Rilley de Sousa Gomes

Projeto de currículo inspirado no site de referência, mantendo o conteúdo temático de Marty McFly / De Volta para o Futuro.

## Tecnologias
- HTML5
- Tailwind CSS via CDN
- JavaScript
- Google Fonts: IBM Plex Mono e IBM Plex Sans

## Publicação
Este projeto pode ser publicado gratuitamente com o GitHub Pages.
